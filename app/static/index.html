🔒 Security & Privacy Protocol:
  • VID verified with Verhoeff $D_5$ Dihedral permutation matrix.
  • Demographic names encrypted using Fernet (AES-128-CBC + HMAC).
  • Raw audio discarded after 192-dim embedding projection.
  • Biometric template hashed with HMAC-SHA256.
